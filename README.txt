GUARNEST SECURITY WEBSITE

Static HTML/CSS/JavaScript website ready for normal static hosting or GitHub Pages with .nojekyll.

Structure
- index.html = home
- about/index.html = /about/
- services/index.html = /services/
- sectors/index.html = /sectors/
- careers/index.html = /careers/
- faq/index.html = /faq/
- contact/index.html = /contact/
- privacy/index.html = /privacy/
- terms/index.html = /terms/
- assets/css/style.css
- assets/js/script.js
- images/ = site images
- favicon.svg and favicon.ico
- .nojekyll

Clean links
Navigation uses clean paths such as /about/ and /services/ and never links to .html files. Home links use /.

Contact form
The contact form is intentionally backend-free. Submitting prepares an email to info@guarnestsecurity.co.uk. If you later use Formspree, Netlify Forms, PHP or another backend, update the form in contact/index.html.

Important publication checks
- Replace image placeholders with photographs you own or are licensed to use.
- Check all service claims reflect services Guarnest actually supplies.
- Have privacy and website terms reviewed against your real company structure and data practices.
- Only add accreditation, membership or certification logos that Guarnest is genuinely entitled to display.
